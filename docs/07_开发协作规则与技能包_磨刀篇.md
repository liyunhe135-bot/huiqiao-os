# 07 · 磨刀篇：开发协作规则、技能包与自动模型切换（磨刀不误砍柴工）

> **定位**：在 M00 开工前，先把「谁管大脑、谁管编码、Token 怎么省、模型怎么自动换」这套开发期协作规则定死，作为汇桥 OS 开发过程本身的元工具。
> **原则**：有人管大脑（贵模型只做判断），有人管编码（中档模型做实现），有人干苦力（便宜/本地模型做样板与单测）；**Token 吞噬机客观存在，就用规则把它关进笼子**；一切「该用哪个模型」由**确定性规则表**裁决，不靠模型自觉。

## 2. Token 吞噬机最小化：八条纪律（写进 rules.md，每会话开头加载）

1. **前缀缓存纪律（收益最大）**：系统提示 + 宪章摘要 + 项目地图固定为每会话不可变前缀、少改；命中缓存 ¥0.025/M vs 未命中 ¥3/M = **120 倍差距** → 同主题任务在同一会话续跑，不开新会话。
2. **上下文纪律**：读文件一律 `offset/limit` 局部读，禁止整仓 dump；长输出先落盘，只把摘要回传主对话。
3. **拆分纪律**：一次只动一块积木（一个 M 单元）；单次改动 ≤400 行；**规格先行**——先 spec/plan/tasks 确认，再写代码，返工是最大的吞噬源。
4. **降级纪律**：默认 flash/chat；只有「spec/审查/疑难调试」才升 reasoner，且升级理由写进预算账本。
5. **评审纪律**：评审用便宜模型 + 规则清单，不用贵模型做校对。
6. **苦力本地化纪律**：单测、样板、文档默认丢本地 4B–7B（API 费 0）；本地模型忙/效果差才回退 flash。
7. **熔断纪律**：每积木超预算 20% 即停，先复盘再续（防止失控烧钱）。
8. **记账纪律**：每次任务结束记 `(积木, 模型档, token, 费用)` 到 `hq-budget.log`，由确定性脚本自动记，每周汇总对比 §5 预算表。

## 3. 自动模型切换规则表（确定性裁决，规则引擎执行）

| # | 触发条件（规则判定，非模型猜测） | 档位 | 预算上限 | 验证门 |
| --- | --- | --- | --- | --- |
| R1 | 文件扩展名 `.md/.yaml/.json` 契约、样板、翻译 | Laborer（本地优先） | 1K–3K token/任务 | 格式/schema 校验 |
| R2 | 单测/测试用例生成 | Laborer（本地优先） | 2K–4K/任务 | `pytest` 通过 |
| R3 | 积木实现代码（有 spec 的任务） | Coder（chat） | 4K–15K/任务 | lint + typecheck + test |
| R4 | spec/plan/架构设计 | Brain（reasoner） | 8K–20K/次 | 人工确认 |
| R5 | 路由/分类/参数抽取 | Laborer 本地 4B Q8 + GBNF | 1K/次 | 结构校验 |
| R6 | 代码评审 | Laborer（flash）+ 规则清单 | 6K/次 | 缺陷清单 |
| R7 | 疑难 bug（同错 2 次修复失败后） | Brain（reasoner） | 10K/次 | 测试通过 |
| R8 | 一切校验/门禁/记账 | Rules（纯代码） | 0 | 自身确定性 |

**执行器**：M00 里的 `hq-model-router` 确定性脚本——读任务类型 + 预算账本 → 按上表选档 → 记录 → 任务完成后回记实际消耗。模型自己无权选择档位（防「什么都上贵模型」）。

## 4. 开发期技能包（5 个 SKILL.md + 2 个确定性脚本）

按渐进披露设计：每个技能只在上下文里留「name + description」索引，命中才加载全文。

| 技能/脚本 | 类型 | 触发描述（写进索引） | 输入 → 输出 | 关键约束 |
| --- | --- | --- | --- | --- |
| `hq-dev-spec` | SKILL | 把模糊需求变成可验收规格 | 需求 → `spec.md`(含 AC: 给定/当/则+负例) + `plan.md` + `tasks.md` | 澄清 ≤5 问；AC 冻结后变更需人工确认 |
| `hq-dev-implement` | SKILL | 按 tasks.md 逐任务实现 | tasks → 代码 + 每步验证命令执行记录 | 单次改动 ≤400 行；每步先跑验证门再下一步 |
| `hq-dev-review` | SKILL | 对照 AC 与风险清单评审交付 | diff + spec → 缺陷清单 + 通过/打回 | 用便宜模型+规则清单；评产物不评路径 |
| `hq-dev-test` | SKILL | 生成测试与金标准题 | 模块 → 测试套件 + fail-to-pass 用例 | 金标准题需可复现、附参考解 |
| `hq-dev-doc` | SKILL | 更新 README/文档/索引 | 变更 → 文档 diff | 只追加必要行；索引同步 |
| `hq-model-router` | 脚本 | 按 §3 规则表裁决模型档位 | 任务类型 → 档位 + 预算 | 纯规则，模型无权自选 |
| `hq-budget` | 脚本 | 记账与熔断 | 实际消耗 → 账本追加 + 超预算告警 | 每次任务必记；超 20% 熔断 |
