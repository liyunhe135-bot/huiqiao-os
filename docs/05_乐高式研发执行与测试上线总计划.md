# 汇桥 OS (HuiQiao OS) 乐高积木式超细颗粒度研发执行与整体测试上线总计划

> **配套 PRD 版本**：[local_lego_agent_os_prd.md](./04_汇桥OS_产品需求文档_PRD_v2.2.md)（v2.2）  
> **核心施工铁律**：
> 1. **做一块、测通一块、完善一块（Brick-by-Brick Completion）**：全系统拆解为 **12 块可独立运行、独立单测、独立发版的乐高施工单元（`M00`–`M11`）**；前一块不通过本块验收标准（DoD）与测试集，绝不开挖下一块。
> 2. **大方向与原则不变，规则不写死（Hard Guardrails, Soft Guidance）**：每一块积木均明确标注 **“必须写死的硬边界”** 与 **“留给模型自由发挥的柔性空间”**，确保底盘稳如磐石、模型创造力不被锁死。
> 3. **双维度透明评估**：明确区分 **研发期 AI 辅助编码消耗的 Token（人力+AI 协同成本）** 与 **运行期本地模型单次任务消耗的 Token（本地离线零边际成本，决定响应速度）**，拒绝拍脑袋估数。

## 1. 总览：全周期工时、双维度 Token 预算与里程碑总表

### 1.1 估算口径与基准假设（透明可复核）
- **人力配置基准**：**1 名主导开发者 + 顶级 AI 编程助手协同**（每天有效深度研发 **6 小时**；若为兼职每天 2–3 小时，自然日历天数乘以 `2.2`）。
- **推荐技术栈**：Python 3.12（`uv` 托管）+ Pydantic v2 + FastAPI + Typer CLI + SQLite（WAL / FTS5 / `sqlite-vec`）+ 原生 MCP SDK；物理采用**模块化单体（Modular Monolith）**，每块积木对应 `packages/<brick_name>/` 独立包与独立测试目录。
- **研发期 AI 编码 Token 估算口径**：每轮高质量编码/单测/Review 交互含上下文（含 Prompt Cache 复用）约 `50K–120K` 总 Token；平均每 100 行生产级代码（含单测与文档修复）消耗约 `150K–250K` 研发总 Token（计入排错与重构余量 30%）。
- **费用参考（按云端编程模型缓存命中折算）**：总计约 **21.6M 研发期总 Token**（其中约 80% 为缓存命中输入 Token，20% 为非缓存输入+输出），实际 API 成本约 **\$35–\$95**（或覆盖于 1–2 个月常规 AI 编程订阅额度内）；系统上线后运行期 **100% 本地模型离线推理，API 费用 \$0**。

### 🧱 积木 `M00`：宪章核心、契约总线与工程底座（3.0 天 | 研发 ~1.0M Token）
- **目标**：定下永不动摇的灵魂与积木插槽规范，确保后续每一块都能真正“即插即拔”。
- **交付目录**：`packages/core/` + `workspace/CONSTITUTION.md` + `config/bricks.yaml`
- **0.5 天级细化任务**：
  1. **T00.1（0.5d）**：初始化 `uv` monorepo 工程结构、统一日志与错误码、`pytest`/`ruff`/`mypy` 质检配置。
  2. **T00.2（0.5d）**：定稿 **`workspace/CONSTITUTION.md`（C00 众生和谐增上宪章正式正文）**——包含五大公理、增上四问模板、反人矿与强扶弱原则，且预留用户共修扩展区。
  3. **T00.3（1.0d）**：用 Pydantic v2 冻结全局核心契约：`TaskEnvelope`、`RouteDecision`、`StepInput/StepOutput`、`CapabilityProfile`、`BrickManifest`、`SkillManifest`、`EventRecord`。
  4. **T00.4（0.5d）**：实现轻量 **Brick Registry（积木插件加载器）**：读取 `bricks.yaml` 动态按接口契约装配实现类，支持配置一键热换与 `fallback_brick` 降级。
  5. **T00.5（0.5d）**：编写 100% 契约序列化/校验单测与模拟热替换单测（MockA ↔ MockB 零改业务代码）。
- **刚性守什么 vs 柔性放开什么**：
  - **刚性**：数据契约强校验、接口协议版本冻结、`CONSTITUTION.md` 最高加载优先级。
  - **柔性**：契约中预留 `metadata: dict` 与 `model_notes` 自由扩展位，不把模型未来新玩法堵死。
- **本块 DoD（不达标不进 M01）**：`pytest packages/core` 100% 通过；仅修改 `bricks.yaml` 即可切换 Mock 积木并打印合规体检报告。

### 🧱 积木 `M01`：本地模型网关、显存亲和调度与思考剥离（4.5 天 | 研发 ~1.8M Token）
- **目标**：打造单机最稳的本地大模型算力入口，彻底治理显存乒乓、低精度崩坏、过度思考与前缀缓存失效。
- **交付目录**：`packages/llm_gateway/` + `config/models.yaml`
- **0.5 天级细化任务**：
  1. **T01.1（1.0d）**：实现统一异步客户端抽象，内置双适配器：**`OllamaAdapter`** 与 **`LlamaServer/LlamaSwapAdapter`**（均走 OpenAI-Compatible API + 离线强制仅允许 `127.0.0.1`）。
  2. **T01.2（0.5d）**：实现角色别名映射（`fast_router` / `coder` / `reasoner` / `embed`）与 **GBNF / JSON Schema 约束解码透传**。
  3. **T01.3（1.0d）**：实现 **VRAM 预算账本 + Model Affinity Queue（模型亲和批处理队列）**——同驻留模型任务自动聚批先跑，避免多任务交替引发反复换模；支持空闲 TTL 释放。
  4. **T01.4（1.0d）**：实现 **DeepSeek/Qwen3 思考管控器**（`thinking_mode: off | low | high` + 流式 `<think>...</think>` 剥离分流器）与 **不可变前缀缓存锁（Prefix Cache Pinning）**（固定前缀哈希监控缓存命中）。
  5. **T01.5（1.0d）**：压测与单测：模拟 10 个交替角色并发请求验证亲和排程减少 ≥60% 换模、断网模式拦截外网 URL 100%、流式 `<think>` 剥离不损 JSON 解析。
- **刚性 vs 柔性**：
  - **刚性**：断网强制回环限制、VRAM 安全水位线（防 OOM）、`<think>` 物理剥离保解析器稳定。
  - **柔性**：允许上层按任务实时覆盖温度、采样参数与思考档位，不强制把所有任务锁成单一温度。
- **本块 DoD**：不改任何调用方代码，改一行 `bricks.yaml` 即可在 `Ollama` 与 `llama-server/llama-swap` 间切换并通过全部并发与流式单测。
