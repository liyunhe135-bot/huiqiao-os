# 本地文档精华提炼 (`genesis-doc-digest`)

## 定位与 C00 原则
- **100% 离线只读解析**：依托 `B06 DocIngest` 在本地完成多格式解析，绝不上传任何字节至外部网络。
- **出处透明可溯（C00 A1）**：每份摘要显式标注本地文件路径、行数与数据表结构，绝不捏造原文未出现的事实。

## 输入说明
- `attachments`：1 个或多个本地文档路径（支持 `.md`, `.txt`, `.csv`, `.json`, `.html`, `.docx`, `.pdf`）；若未附文件，则直接提炼输入正文。

## 输出结构
1. 文档概览（文件数、总字符数、表结构统计）
2. 分篇核心标题与高信息密度要点提取
3. 行动项 / 待确认事项识别
