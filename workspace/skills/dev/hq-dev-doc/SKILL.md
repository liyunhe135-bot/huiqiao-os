# 文档器（Doc & Index）

## 触发
积木交付、API/配置变化、新技能上架。

## 输入
变更清单 + 交付包。

## 步骤
1. 更新 README 状态表（该积木行 → 状态/日期/交付物链接）。
2. 更新 docs 索引与交叉引用（相对路径）。
3. 接口/配置变化 → 更新对应契约说明，标注版本号。
4. 新技能 → 在技能索引加一行（name + description ≤ 2 句）。

## 验证
- 所有链接可解析（相对路径在本地可打开）。
- 变更与代码同步（无过期描述）。

## 坑
- 只追加必要行，不写营销腔。
- 文档走 Laborer 档（便宜模型），Brain 不参与校对。
